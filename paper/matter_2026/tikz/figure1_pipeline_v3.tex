%% ============================================================================
%% Figure 1 (v3): end-to-end pipeline from synchrotron tomography to additively
%% manufactured lattices -- two tiers joined by the data-contract layer.
%% Author  : Cameron B. Renteria
%% Purpose : Replaces the six-stage v2 schematic with the eleven stages of the
%%           pipeline as described in the v3 manuscript (Results 2.1, Table 1):
%%           MEASUREMENT  projections -> Noise2Inverse denoising -> U-Net
%%                        segmentation -> watershed rod detection -> PIV
%%                        tracking -> morphometric features
%%           TRANSLATION  feature-to-CAD -> FEA -> design optimization ->
%%                        digital twin -> additive manufacturing
%%           The tiers exchange only schema-validated JSON contracts with
%%           recorded provenance (centre band).
%% Images  : every ring holds a crop of this study's data
%%           (figures/panels/thumb_*.png from make_thumbnails_v2.py and
%%           make_thumbnails_v3.py). The first two rings (projections,
%%           denoising) are vector glyphs, not data: the raw lion
%%           reconstructions are not part of this repository.
%% Build   : (from figures/src/)
%%           pdflatex figure1_pipeline_v3.tex
%%           cp figure1_pipeline_v3.pdf ../figure1.pdf
%%           pdftoppm -png -r 600 -singlefile figure1_pipeline_v3.pdf ../figure1
%% Output  : 17.4 cm x 10.8 cm vector PDF (Cell Press double-column width).
%% ============================================================================
